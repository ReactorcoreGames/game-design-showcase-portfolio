# Game Design Technology: The Holy Grail of Fun

A book by Reactorcore. Offline edition.

## How to read it

Double-click **Read the book.html**. It opens the book in your web browser, with the contents page first. (If it doesn't, open `book/index.html` instead.)

Everything is inside this folder: the text, the fonts, the images. No internet connection is needed, nothing is installed, and you can copy the folder to any computer, tablet or phone that has a web browser. The contents list sits beside the text on wide screens and folds into a "Contents" box on narrow ones. Every chapter has previous and next links at the bottom.

Prefer an e-reader or a reading app? Grab the EPUB edition from the same itch.io page. It's the same book, with a simpler layout that your reader can restyle.

## What's in the book

Where fun really comes from, and how to design for it on purpose. It's a method for game design built on the human needs that every game either meets or violates, carried from the first idea through to the finished, shared and supported game. Five parts and 34 chapters, plus quick-reference back matter: the needs at a glance, a question kit, a padding checklist, further reading and a glossary. About 90,000 words.

## Using what's in it

The ideas are free. Copy them, teach them, use them in your own courses or videos, build games on them and make money with what the book gives you. That's what it's for. A mention is appreciated.

The whole book is also free to read online: https://reactorcoregames.github.io/game-design-showcase-portfolio/book/

Buying this offline edition is how you support the book. Thank you.
