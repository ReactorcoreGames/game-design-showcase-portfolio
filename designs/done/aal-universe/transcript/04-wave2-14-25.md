## New terms
- **Potency**: a far-vision/loading score for an object (size, brightness, significance vs distance); load it only if potency > X. "Potency-based event horizon".
- **Type 1 / Type 2 (far view)**: Type 1 = realistic, potency-based, no distance limit, one global sorted list of objects; Type 2 = sector/distance/area based with a hard limit (100 AU), sectors with their own object lists, subsectors by scale.
- **Sector separation space**: empty buffer space between Type 2 sectors.
- **Event horizon (loading)**: the distance at which an object of a given size class transitions between loaded/visible and unloaded, or between BG and active; each size class (small, medium, large, huge, moons, planets, stars, galaxies, super big objects) has its own.
- **BG / BG mode / REAL**: the background layer (desaturated/bright/dark depiction) vs the real, active simulation layer; objects can travel between them (e.g. ICBMs) and be "mirrored" across.
- **Maximum spawn range**: the outermost distance at which the biggest objects exist at all.
- **Active / visible / buffer zone**: extra active margin around the visible screen for zooming out and moving the camera Soldat-style.
- **Maximum / med-high / low accuracy**: simulation fidelity bands by distance.
- **Chaos Flux**: the build-up rate of processing load/chaos; drives Light chaos and Heavy chaos responses, far objects degraded first.
- **Light chaos / Heavy chaos**: graded anti-lag measures (light: minimal physics, no visibility, fog, sleep; heavy: physics shutdown, temporary unload, outside events disabled).
- **Overpowering effect**: an immediate-area optimization listed with merging/grouping; meaning not explained (likely a dominant effect hiding/absorbing smaller ones).
- **Aerodynamic state / Resting state**: active-mode (physics) vs BG-mode (static background) form of an artificial object; shifting only by direct player command. "Stacked BG mode", "BG shifted char."
- **System Layers**: the engine's rendering/simulation layer stack (GUI, Lighting, Energy areas/entities (Forces), Foreground objects, Solid active objects, Background objects, Background local atmosphere, Astral Plane, Major Vehicles/Buildings, Terrain, Loose Materials/Gibs, Chaos Monitor).
- **Movable Frames**: written for Major Vehicles/Buildings, apparently the same as Moving Frames / M-Frames.
- **Gen proc (flora)**: procedural generation of flora from an area's abstract species + stats when it is visited (unloaded/far/old).
- **Pulsar Planet**: a space element, a spinning body blasting radiation at a nearby planet.
- **TEMGRAV / V-TEMGRAV / MF-TEMGRAV** (show-through only, from another page): an equipment naming scheme; V = variable, MF = multi-function.
