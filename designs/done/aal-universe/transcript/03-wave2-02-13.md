## W2-3 — Anti Butterfly effect
Source: `Wave 2 PW Docs (3).jpg`

**Text:**

Anti Butterfly effect

This is a system for omitting small/tiny details in the event of a large, overpowering or overwhelming event.

An example is when a huge bomb explodes on a surface of an earth-like planet. At the same time, there were tiny events taking place on the surface, like a small chemical reaction, a guy producing smoke, plant spewing water... and so on.

The scale, speed and power of these tiny events dwarf at the face of the larger, overwhelming bomb detonation event.

Once the force collides with these smaller events, they cancel their function and visual representation, only leaving the molecular mass with which the explosion either turns into dust, imprints onto terrain or pushes into a nearby airmass to be absorbed into.

It depends on the material what happens to the object. The omitting effect only happens if the active force overpowers the objects that it collides with and has an effect on.

No values are ever lost, only the computational method changes to a more broad one.

**Diagrams:** none.

**Notes:** Part of the Chaos System / anti-lag family; "molecular mass" ties to the Molecular system and equivalent exchange (no values lost). Bleed-through of the Passage of time page behind it.

## New terms

- **Anti Butterfly effect**: the opposite of the butterfly effect: when an overwhelming event (huge bomb, asteroid strike) hits, all the tiny events it overpowers have their function and visuals cancelled and are reduced to their molecular mass (dust, terrain imprint, absorbed into air). No values lost; only the computation becomes coarser.
- **Simulation Level of detail**: automatic, on-demand simulation LOD triggered by large views, high speed past a threshold, or cataclysmic events; more powerful objects/forces get simulation priority.
- **Travel Levels 1–5**: 1 small scale/low speed (planet surfaces), 2 extended scale/high velocity (normal space, atmospheres), 3 interstellar FTL (hyperspace), 4 intergalactic over-FTL (warp/hyper acceleration), 5 interuniverse ∞ FTL (hyperverse). 1–2 "Real", 3–4 "UI based / virtual, sensor based".
- **Entry Field**: the zone around a planet where a ship transitions between orbit and landing.
- **LZ**: landing zone.
- **Visual-only modes / sensor view levels**: overview maps are views through an in-world sensor device with an optics interface; stronger sensors give higher view levels; views can be infrared, radiation, pressure etc.; the viewer's perception affects usability.
- **Speed layer**: the high-velocity gameplay level; anything above it is a sensor interface view.
- **General sector**: a massive cell in the galaxy's grid whose properties seed the random generation of empty space between starzones.
- **FTL Phase Field**: graviton field distortion around an FTL-travelling object that phases through or pushes aside anything smaller than stellar-class; only stellar-class objects can be crashed into at FTL.
- **Hybrid loading screen**: loading screen during FTL where only the spacecraft is loaded and simulated (as in Starbound).
- **Event horizon box / object event horizon / star event horizon**: in far vision, the central box where distant objects first appear; different object classes have different horizons (detection up to 100 AU max).
- **Infinity star**: the vanishing point at the centre of the far-vision background where everything at maximum distance converges.
- **High velocity mode (X) / Epic scale mode (Y)**: two zoom-out modes: X = 50% zoom on foot with binoculars / high velocity; Y = 25% via interface for ultra-high velocities, if optics support it.
- **RCG**: Reactorcore Games (the blog in the todo note).
- **Launch Sequence**: heading only on W2-13 left page, no content.
