# Transcript chunk 1: Wave 1, scans 1–12

These are the earliest Planet Warfare notebook pages: the 2011-era concept of a space/planet war game with a turn-based strategic layer, top-down space combat and side-view planet combat.

## New terms

- **SP / MP / OPT / CRE / EX** (W1-2): main menu items, read as Single Player, Multiplayer, Options, Credits, Exit.
- **CAM / SCE** (W1-2): Campaign and Scenario.
- **GAL / SYS** (W1-2): campaign scale choice, galaxy vs (solar) system.
- **ADV OP** (W1-2): Advanced Options (starting fleet, allowed tech).
- **BC** (W1-1): an asset in the Assets list, most likely battlecruiser (the large ship).
- **Engineer View / Navigator View** (W1-1): multi-crew role screens; the engineer splits power (shield/weapons/thrust) and per-facing shields, the navigator sees the tactical map with fog of war.
- **BG / BG targeting** (W1-4): background layer; bunker modules sit in the background layer and can be targeted there.
- **Shard System** (W1-4): local destructibility of modules into auto-defined fragments, after Red Faction.
- **Information Warfare** (W1-3): umbrella for fog of war, detection, intel, scanning, security grids, signal jammers, Clonk-like FOV.
- **Security grids** (W1-3/W1-4): capturing a building's security room reveals the whole building's interior.
- **Locations of Control / Node system** (W1-6): strategic map nodes; bold nodes are custom maps, small nodes generic empty-space maps; edges cost travel time (1 day).
- **Techs** (W1-3): "What you can build" (the tech list, with groups/items that can be enabled or disabled).
- **Device / Thruster / Chassis, Fire spawn / Thrust spawn** (W1-10): ship composition parts; spawn points are where shots or thrust emerge, any number per part.
- **Persistent Galaxy** (W1-11): the Conquest mode's name.
- **Homeworld Defence / Assault Campaign / Skirmish Battle** (W1-11): game modes.
