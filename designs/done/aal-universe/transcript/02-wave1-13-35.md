## New terms

- **EN**: energy units, the cost unit for force/heat in the element-based content system (alongside RU for material) (W1-13).
- **Interfaceable device class**: a scriptable platform template for items/tools/guns built from device functions (create particles, force, trigger, timer, remote receiver) (W1-13).
- **Entity Framework / Entity Core / Locomotional Limb / Active Function Unit**: successor to Moving Frames: a core with operation requirements, base functions, limb pivot slots, control system and UI; limbs give movement; function units add active functions and UI "drivers" to the core (W1-18).
- **Framewall / solid M-frame / FG item / BG item**: cell contents inside an M-frame grid (W1-18).
- **Huge List (o' Stuff) / Active List**: the disk-backed tree-structured reference database of all unique materials, objects and areas, from which the active list builds the game scene (W1-26, W1-27).
- **Instant switch range**: radius within which the player can switch to another character without loading (W1-28).
- **Seamless Space Transition / Transit**: the 5–10 s zoom-and-rotate sequence from top-down space view to side-view planet surface (W1-15, W1-16).
- **Energy Graphic Types / light types**: line laser, radial spotlight, point light, shaped (image-based, animatable) light, directional (ambient) light, polygon light; lights can take texture filters (W1-30).
- **Distribution models A/B/C**: auto-loaded standardized mods, manual database browsing, or a hybrid (W1-20).
- **Combat mode / Builder mode**: key-toggled control/interface modes (W1-34).
- **Toxigun / Fertigun**: bio-clearing weapon and its regrowth opposite (W1-34).
- **2-Stage Health System**: 100 auto-regenerating short-term health over 1000 long-term health that needs healing (W1-34).
- **B.S.L. Enviro-sim**: the HQ's containment/environment simulation room for captured lifeforms, probably "Bio Safety Level" (W1-32).
- **Alien Standard Alphabet**: an A–Z substitution script for alien text (W1-35).
- **PSP9**: Paint Shop Pro 9, the graphics editor he imagined built into the game (W1-20).
- **LP2 / VS**: Lost Planet 2 and its Vital Suits, reference for powersuits (W1-34). **HL2 antlion thumpers**: Half-Life 2 reference for repellers (W1-33).
