Was thinking about a traditional fighting genre game and how to make a fun game design for it. Then I remember divinoids and thought what if I'd model it after that, mixed with Pokemon RPG or TCG, heavily delayed devastating attacks, while using buildings as cover.

V2 idea:

Multihero + Divinoids. Plus minor influences from various fighting genre games.

The main point is Multihero's controls, health system, slow pace speed and simplified physics, but Divinoids mechanics, with buildings, megatanks, small units as setting, along with transforming characters (humanoid mech / mythical beast), 3 equippable melee/ranged enhancer augments and equippable 2 special ability modules.

This intentionally bringing Smash bros like simplified controls, maybe even Divinoids style controls, but mostly omitting the "get pushed farther with more damage" thing, in favor of "start with 100hp, if you hit zero, you explode, gg".

It's like merging Rampage with Super Smash Bros. Break buildings, battle rival kaijus/giant robots, etc.

The biggest draw is the character system that lets creating diverse characters with an intuitive auto balancing system based on mass, sophistication, output power to determine health, damage, mobility, versatility. Some characters can use ammo, some cooldowns, some heat meters. Some transform or mode switch, some don't. People can implement any smash bros character they've ever wanted or any pokemon they want as a smash-like fighter, but with a catch that it's always a 20 meters tall giant robot/cyborg/beast.

Game features traditional fighting game combat with platforming elements (sort of like Street Fighter 2 HP bars mixed with Super Smash Bros' controls) and environmental destruction (destroy buildings, trees, bridges, props, etc. ala Rampage/Divinoids), but also typical platformer game style stage hazards, such as things seen in GBA Super Mario or GBA 2D Sonic the Hedgehog games. (GBA = Gameboy Advance)

There's potential for an adventure campaign (a mix of Divinoids+multihero adventure stages) or vs battles (Divinoids+multihero arena stages).

Benefit of the game is minimal IMAJ (idle, move, attack, jump) sprites, standardized hit effects (light, smash, super), orb shield. Custom projectile sprites, unless they're beams which use a universal customizable system (think cryptark lasers). Same with common phenomenon like fire, gas, plasma, explosions, lightning. They can be color tinted though!

Characters are generally somewhere along 64-96-128px2 sprites with hitboxes that match their shape on the canvas.

Lorewise you play as alien conquerors against basic modern tech locals with puny conventional armies with occasional prototype rival titans or massive superweapon structures. Think series like Voltes V, Power Ranger Megazord fights, Super Robot shows, Godzilla, Pacific Rim, etc. but you play as the bad guys. (It gives the player the needed excuse to wreck buildings and blow stuff up).


Context for AI:
Multihero is a PC freeware clone of Super Smash Bros in all aspects but using 2D sprites and with greatly simplified moveset systems, audiovisuals and other elements - yet it still rivals SSB in how fun it is to play. It even has a platformer adventure mode where players use smash bros characters to go through various gauntlet levels with lesser enemies, nemesis enemies, boss enemies, hazard courses with sources of damage to avoid while doing semi-challenging platforming parkour segments.
Divinoids is a PC indie game that is a clone of the classic NES game Rampage where player controls an oversized beast with powerful attacks, attacking buildings, naval ships, giant tanks, and conventional military forces.
Pokemon RPG/TCG both feature preset abilities that can be used to attack, defend, enhance self, or weaken the opponent. Those abilities come with rechargable energy mechanics and costs and a slowness/deliberate pace that comes with turn based combat - but made real time, emulating that same slowness of turn based combat.

Generally controls would be something akin to this:
- WASD directional movement, including jumping and crouching/ducking/dropping
- mouse to aim attacks, mouse 1 for main attack and mouse 2 for secondary attack
- Q and E for using equipped ability modules that act as tertiary and quaternary attack functions
- (note: the attacks can be defensive/protective moves too)
- R to transform between humanoid and beast mode
- ESC to open pause menu
- F for using a dodge or shield or some other damage mitigation that is unique per each playable character
- X activates super ability
