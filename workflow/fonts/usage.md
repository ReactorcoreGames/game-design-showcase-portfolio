# Font usage

Generated by `python tools/fonts.py list` from `licences.txt` and the `FONTS` list in `tools/brand.py`. Don't edit by hand; rerun it after adding a font to a page.

`assets/fonts/` holds 275 font files. 58 carry a CC0 or SIL OFL licence in the file itself, which is what the page brief prefers; 55 of those are in use. The rest have another licence (CC BY-SA, BY-ND, non-commercial, freeware) or none embedded at all (`?`), so check each one's terms at its source before using it. Fonts that spill outside their own metrics are in `assets/fonts/nah/` (see `python tools/fonts.py scan`).
