# Font samples

A ready-made look at the display fonts in `assets/fonts/` that are safe to self-host, so a page can pick its fonts without re-rendering samples every session.

- `licences.txt`: every font file in `assets/fonts/` with its embedded licence (name IDs 13/14) and `fsType`, one per line as `class|fsType|file|licence|url`. The class column marks `OFL` and `CC0` fonts; the rest are blank (freeware, CC BY-SA/ND, unknown), which the page brief says to avoid.
- `samples-1.png`, `samples-2.png`: the CC0 and OFL candidates rendered with the same test line (it includes `&`, digits and `Qg`, the glyphs that most often surprise).
- `samples-0-in-use.png`: fonts already taken by a page. Which page uses which is in the `FONTS` list in `tools/brand.py`; check it before choosing, so no two pages share a pair.
- `usage.md`: every font in `assets/fonts/` with its licence class and the page using it, CC0/OFL first. Generated by `python tools/fonts.py list`; rerun it after giving a page its fonts.

`assets/fonts/` has about 275 fonts, but only the ~58 with a CC0 or SIL OFL licence embedded are in the samples. The others carry CC BY-SA, BY-ND, non-commercial or freeware terms, or no licence in the file at all; check a font's terms at its source before self-hosting one.

`python tools/fonts.py scan` measures how far each font's glyphs reach outside their own advance width and ascent/descent. Fonts that spill badly overlap their neighbours, get clipped, or push a title past the screen edge on phones; `scan --move` puts them in `assets/fonts/nah/` (it never moves a font a page uses). TypeLight Sans (a stray 'p' and 'X') and Motion Control (its WOFF2 won't decode) went there, so ignore them in the sample sheets. Audiowide's 'j' spills 0.22 em but City Buster uses it without trouble.

If fonts are added to `assets/fonts/`, rerender the samples and the table and replace these files.

Gotchas found so far: Zero Hour's `&` looks like an 8; the Zeroes family draws capital C like a lowercase one, so "City" reads "city"; Zector is a hairline face that vanishes over a busy or pale image, so keep it out of subtitles; the pixel fonts need room to read as kickers: about 1–1.25rem for 6809 Chargen and Jersey 10, and 1.5rem for Micro5, which draws very small for its size. Motion Control's WOFF2 fails to decode in Edge and Chrome (the page falls back to Segoe UI), so it's unusable as built; Hydrogen Whiskey draws A without a crossbar (Λ), which stays legible in titles, and its & looks like a 6. Dendritic Voltage's capital B reads as a 3, and World of Water's lowercase a reads as an o, so set World of Water titles in capitals. Check `document.fonts` statuses in headless Edge rather than trusting a screenshot.
